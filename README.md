# Anugrah Group - Corporate Website

Website company profile resmi untuk **Anugrah Group** (Venture Builder & Financial Holding Company). Website ini dirancang modern, interaktif (3D Card), dan responsif untuk semua perangkat.

## 🛠️ Teknologi yang Digunakan

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animasi:** [Framer Motion](https://www.framer.com/motion/) (untuk kartu 3D & transisi)
- **Icons:** [Lucide React](https://lucide.dev/)
- **UI Components:** [Shadcn UI](https://ui.shadcn.com/)

## 🚀 Cara Menjalankan Project (Wajib Dibaca)

Agar tidak terjadi error *"Module not found"* atau *"Next is not recognized"*, ikuti langkah ini berurutan:

### 1. Persiapan (Prerequisites)
Pastikan laptop kamu sudah terinstall:
- **Node.js** (Gunakan versi LTS terbaru, minimal v18). [Download disini](https://nodejs.org/).
- **Git**.

### 2. Clone & Install
Buka terminal (Command Prompt / PowerShell / Terminal VS Code) dan jalankan:

```bash

# 2. Masuk ke folder project
cd Compro_Anugrah

# 3. PENTING: Install semua dependencies (JANGAN LEWATKAN INI)
